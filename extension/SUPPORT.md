# Support

Report bugs and feature requests on
[GitHub Issues](https://github.com/tensorviz-org/tensorviz/issues).
Include the extension version, editor version, operating system, whether you use
local VS Code or Remote SSH, the selected model Python and PyTorch versions,
reproduction steps, and a small example if you can share it.
Remove credentials, private code, and paths from logs before you post them.

Security reports: [SECURITY.md](../SECURITY.md).
Development setup: [CONTRIBUTING.md](../CONTRIBUTING.md).

The source is this repository, which is currently private and requires read access
to clone. You do not need source access to use a published package or ask a question.
See the public [setup and troubleshooting guide](https://tensorviz.dev/install.html#support)
and [compatibility guide](https://tensorviz.dev/install.html#compatibility).
