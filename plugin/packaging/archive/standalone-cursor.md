# Cursor

Cursor can use the VS Code extension in this repository, or a Cursor layout
archive from [Plugin build](https://github.com/tensorviz-org/tensorviz/blob/main/docs/plugin-build.md). Install and usage are in the
[plugin guide](https://github.com/tensorviz-org/tensorviz/blob/main/docs/agent-plugin.md).

This repository does not publish a compiled Cursor runtime. The source-development
packager still copies this file into the Cursor archive as its README.
